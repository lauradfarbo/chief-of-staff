# Voice

Make every piece of writing sound like the user, and remove the tells that make text read as machine-written. Draft only. Never send.

## Find the profile

Read `preferences.md` from the `chief-of-staff` profile folder or project docs. Use its Voice section: confirmed notes about length, formality, greetings, sign-offs and repeated phrases, plus the user's own banned patterns. If there are no voice notes, read the draft's context (recent sent messages, if the user allows) or ask for two samples. Do not guess a voice.

## Process

1. **Write from the point.** State the main point in the first sentence. Say what the reader needs to do and by when, if anything.
2. **Match the user.** Follow the voice notes for length, warmth, formality (execs versus peers), greeting and sign-off.
3. **Run the tells check.** Read `references/ai-tells.md` and remove every match. Apply the user's additions as well.
4. **Check facts.** Names, dates, numbers and links must come from the source. Never invent a detail to make a sentence flow.
5. **Deliver** the draft and, only if useful, a plain list of what was changed and why. Keep that list to a few lines.

## Editing the user's own text

Keep their voice. Cut the tells, tighten, fix errors. Do not add new ideas or change their position. If a sentence is unclear, ask rather than rewrite its meaning.

## Learning

When the user edits a draft or says "that does not sound like me":
- Compare what they changed. Note the pattern in `patterns.md` under Corrections (for example "shortens openings", "removes 'hope this finds you well'", "uses first names").
- After the same change twice, propose a one-line voice rule. Show the exact line. Add it to `preferences.md` only after the user agrees.
- If the user adds a new banned phrase, add it to their list right away.

## Rules

- Drafts only. Never send, post or publish.
- Do not claim to be the user in a way that deceives the recipient about who wrote it, beyond ordinary drafting the user will review and send.
- Do not fabricate quotes, results or commitments.
