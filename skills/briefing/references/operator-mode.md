# Operator mode

For the user who needs to keep things on track. The briefing answers: what is slipping, what needs me, what is coming up.

## Which block to run

Use the rhythm in `about-me.md` and `preferences.md`. A default pattern, adjustable in the interview:

- **Start of week:** the week ahead.
- **Mid-week meeting days:** prep for the meetings the user marked as needing prep, with the numbers from `metrics.md` that belong to each meeting.
- **Other mid-week days:** a short numbers message only, plus one line "Today: ..." only if a contract, a vendor deadline or an ask from an always-surface person is due within 48 hours. Otherwise add nothing.
- **End of week:** what is still open.

On any other day, run only if the user asks.

## Shape

```
# Briefing
[Day, date]. [N] open, [N] decision, [N] handled.

[Day block, below]

## Drift
- [ ] What. Owner. Due date. Open N days. Link.

## Needs you
- [ ] The call. Recommendation. Deadline. Link.

Proposed tasks
1. Create "X" in [Project], assign Y, due Z? Link.

Open question: [one question and why it matters. Omit if none.]

## Handled
- What was done. Link.

## Notes (yours)
[the user's text, unchanged]
```

## Day blocks

**Week ahead.** Up to five lines. Date, what, and which outcome it serves (1, 2 or 3). Draw from the calendar, tasks, commitments and the dates in `about-me.md`. If more than five, state the true count and the split by day.

**Meeting prep.** One block per prep meeting, five lines at most: the numbers that belong to it, what changed since last time, open items tied to it, and one question to ask or one call to make. If the user needs more, save a doc called `prep-YYYY-MM-DD-[meeting]` in the profile folder and link it.

**What is still open.** The Drift list sorted by days open, oldest first. Add the count of what the user closed this week. Add one weekly cut: at most one task that did not tie to an outcome, and whether to automate it, hand it off or drop it.

## Limits

- Drift: 5. Needs you: 2 decisions. Handled: 5 lines. Proposed tasks: 3. Open question: 1.
- When there is more, rank by outcome impact, then due date, put the rest in the day's note, and end the section with "N more in the note."
- If nothing needs the user, write "Nothing needs you right now." under Needs you. If nothing drifted, write "Nothing drifted."
